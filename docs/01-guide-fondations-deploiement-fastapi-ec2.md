# Niveau 1 — Fondations : Déployer FastAPI sur EC2

## Avant de lire ce guide — comprendre les mots-clés

| Mot technique  | Traduction humaine                                              |
|----------------|-----------------------------------------------------------------|
| EC2            | Un ordinateur dans le cloud AWS que tu loues à la demande       |
| SSH            | Une connexion sécurisée et chiffrée vers cet ordinateur distant |
| PEM            | Le fichier qui sert de clé physique pour ouvrir cette connexion |
| FastAPI        | Un framework Python pour créer des APIs rapidement              |
| Uvicorn        | Le moteur qui fait tourner FastAPI (comme un moteur de voiture) |
| venv           | Un espace isolé pour installer les dépendances Python           |
| systemd        | Le gestionnaire qui démarre/arrête les programmes sur Linux     |
| Security Group | Le pare-feu virtuel qui contrôle qui peut accéder à ton serveur |
